# DC3 ZHAireS Test Library

This directory contains a ZHAireS implementation of the DC3 Test Library. 
It is intended to be used with the DC3 framework to test everything.

Its 250 events in the shower library, and only the indispensable files are kept in the output (.sry files, and antenna traces)

It takes some time to reproduce, try not to modify it.

## Usage

The outputs are already provided in the repo. Should you want to generate your own, you can:

1 Create a new directory
2 Copy the ini file there
3 Adapt the ini file accordingly
4 Run the DC3 chain with it

To regenerate the Showers and their input files, you will have to have ZHAireS properly installed in your system, of course.
