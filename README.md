# DC3
Building the tools to create a library that can be used to study the detection efficiency of a given flux.

For the purpose of this, the flux is considered to be passing through a circular? area on a flat plane

The detector will be the antennas, mounted on top of some 3D topography, that is itself mounted on top of a round earth of appropriate radius.


# Objectives
- Create a DC3FluxGenerator, that creates event geometries and energies according to some distributions.
  -- It outputs a database with Primary, Energy, LocalZenith, LocalAzimuth, EventWeight, RandomSeed
  -- The output should be done in a way that can be parsed to generate ZHAireS or CoREAS inputs to simulate the showers.
  
- Create a DC3[ZHAireS/CoREAS/etc]ParticleShowerInputGenerator, that creates the inputs
  -- It reads the database generated by the DC3FluxGenerator. 
  -- It outputs the input files to run the PARTICLE simulations (to avoid running thousands of untriggereable sims)

- Create a DC3[ZHAireS/CoREAS/etc]XmaxGetter, that gets the Xmax that will be the key to estimating the triggereable antennas     
  --It reads the database generated by the DC3FluxGenerator and the PARTICLE simulations produced
  --It outpus a new database adding LocalXmaxPosition (East,North,Up)
  --A plot of the Xmax Distributions by pramary would be nice to have

 - Create a DC3EventGenerator, that throws cores in random positions in some area, and decides what is worth simulating or not.
  --It reads the database generated by the DC3XmaxGetter
  --It reads the antenna positions
  --It reads the topography  
  --It outputs a new database whit the generated events, each with: 
    --- The Primary, Energy, LocalZenith, LocalAzimuth, EventWeight, RandomSeed, LocalXmaxPosition (East,North,Up)  
    --- A trigger flag 
    --- The list of antennas tagged in the event for simulation 
    --- Their position relative to the core (E,N,Up)
    --- Their expected signal strength (or the full trace?)
    --- The list of core positions tested before triggering
    --- The weight re-normalization.   
  
  -- The output should be done in a way that can be parsed to generate ZHAireS or CoREAS inputs
 
  -- It should have "dry run" mode where plots of the generated distributions are produced, but no files, to be able to play with the parameters.

  -- It would be nice to sample events only in a bracket of distances, to add events to the library, and provide weight re-normalization

 - Create a DC3[ZHAireS/CoREAS/etc]RadioEventGenerator, that produces the inputs for the RADIO Event
  -- It reads the database generated by the DC3EventGenerator
  -- It outputs the input files to run the RADIO simulations
